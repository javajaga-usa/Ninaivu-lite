# நினைவு லைட் — பயனர் வழிகாட்டி

[Read in English](USER-GUIDE.md)

நினைவு லைட் உங்கள் குடும்பப் புகைப்படங்களையும் காணொளிகளையும் வீட்டிலுள்ள அனைவருக்கும், அதே Wi-Fi-இல்
உள்ள எந்தக் கைப்பேசி, டேப்லெட், கணினியிலும் காட்டுகிறது. இது உங்கள் புகைப்படக் கோப்புறைகளை
**படிக்க மட்டுமே** செய்யும்: எந்தப் படத்தையும் நகர்த்தவோ, திருத்தவோ, நீக்கவோ செய்யாது.

## 1. தொடங்குதல்

1. python.org இலிருந்து **Python 3.10 அல்லது புதியதை** நிறுவவும். Windows-இல்
   *Add python.exe to PATH* என்பதைத் தேர்ந்தெடுக்கவும்.
2. நினைவு லைட்டைப் பதிவிறக்கி, நிலையான ஓர் இடத்தில் விரிக்கவும் (எ.கா. `C:\Ninaivu-lite`).
3. **`start.cmd`** ஐ இருமுறை சொடுக்கவும் (Windows), அல்லது **`./start.sh`** இயக்கவும் (macOS, Linux).
   முதல் முறை ஓரிரு நிமிடங்கள் ஆகும்; ஒருமுறை இணையம் தேவை.
4. உலாவி `http://localhost:8080` இல் திறக்கும். சாளரத்தில் `http://192.168.1.20:8080` போன்ற
   முகவரியும் காட்டப்படும் — அதைக் கைப்பேசிகளிலும் டேப்லெட்டுகளிலும் திறக்கவும்.

குடும்பத்தினர் பயன்படுத்தும்போது சாளரத்தைத் திறந்தே வைத்திருங்கள்; மூடினால் நினைவு லைட் நின்றுவிடும்.
கணினி தொடங்கும்போதெல்லாம் இதுவும் தொடங்க, `tools\start-with-windows.cmd` ஐ ஒருமுறை இயக்கவும்
(நிறுத்த: `tools\start-with-windows.cmd off`). Linux-இல் `tools/ninaivu-lite.service` பயன்படுத்தவும்.

## 2. முதல் நாள்

1. முதல் வருகையில் **நிர்வாகிக் கணக்கை உருவாக்கச்** சொல்லும்: உங்கள் பெயர், பயனர்பெயர், குறைந்தது
   8 எழுத்துகள் கொண்ட கடவுச்சொல். கைப்பேசியிலிருந்து அமைத்தால், நினைவு லைட் சாளரத்தில் காட்டப்படும்
   **அமைப்புக் குறியீட்டையும்** கேட்கும்.
2. பின் நிர்வாகப் பக்கம் உதவும்:
   - **புகைப்படக் கோப்புறையைத் தேர்வு செய்யுங்கள்** — அதைத் தேடிச் சென்று *இந்தக் கோப்புறையைப்
     பயன்படுத்து* என்பதை அழுத்தவும். மேலும் கோப்புறைகளைப் பின்னர் *நூலக அமைப்புகள்* இல் சேர்க்கலாம்.
   - **குடும்பத்தினரைச் சேருங்கள்** — *நபர்கள்* பக்கத்தில் *ஒருவரைச் சேர்*: பெயர், பாத்திரம்,
     உள்ளே வரும் வழி (ரகசியம் இல்லை, PIN, அல்லது கடவுச்சொல்).
3. அட்டவணையிடல் தானாகத் தொடங்கும். கிடைக்கக் கிடைக்கப் படங்கள் தோன்றும்; சிறு முன்னோட்டங்கள் பின்னணியில்
   உருவாகும். பெரிய நூலகத்துக்கு முதல் முறை நேரம் ஆகலாம்; பின்னர் விரைவாகத் தொடங்கும்.

## 3. பாத்திரங்களும் யார் எதைப் பார்க்கலாம் என்பதும்

| பாத்திரம் | செய்யக்கூடியவை |
| --- | --- |
| **நிர்வாகி** | அனைத்தும்: கோப்புறைகள், மக்கள், யார் எதைப் பார்க்கலாம், அமைப்புகள் |
| **குடும்பம்** | பொது, குடும்பப் படங்களைப் பார்த்தல், பதிவிறக்கம், விருப்பங்கள், ஆல்பங்கள், பகிர்வு இணைப்புகள் |
| **விருந்தினர்** | பொதுப் படங்கள் மட்டும் |

ஒவ்வொரு படமும் இவற்றில் ஒன்று:

- **பொது** — அனைவரும், விருந்தினர்களும் *சுற்றிப் பார்க்கிறேன்* வருகையாளர்களும் உட்பட
- **குடும்பம்** — குடும்பத்தினரும் நிர்வாகிகளும் (புதிய படங்களுக்கு இயல்புநிலை)
- **மறைக்கப்பட்டவை** — நிர்வாகிகள் மட்டும்

இதை நிர்வாகப் பக்கத்தில் **யார் பார்க்கலாம்** பக்கத்தில் அமைக்கவும்: ஒரு கோப்புறையையும் நிலையையும் தேர்ந்தெடுக்கவும்.
அந்தக் கோப்புறைக்குள் உள்ள அனைத்துக்கும், பின்னர் சேர்க்கப்படும் படங்களுக்கும் அது பொருந்தும்.
நிர்வாகிகள் படத்தொகுப்பில் ஒரு படத்தைப் பார்க்கும்போதே அதை மட்டும் மாற்றலாம். கோப்புறை மாற்றத்தைத்
*அந்த மாற்றத்தைத் திரும்பப்பெறு* மூலம் திருப்பலாம்.

ஒருவருக்கு **ஒரு கோப்புறையை மட்டும்** (எ.கா. `Trips`) கொடுக்கலாம்: அதற்கு வெளியே அவர் எதையும் பார்க்க மாட்டார்.

## 4. உள்நுழைதல்

படத்தொகுப்புப் பக்கத்தில் ஒவ்வொருவரும் தம் படத்தைத் தொடுவார்கள்:

- ரகசியம் இல்லாத சுயவிவரம் உடனே திறக்கும்;
- **PIN** அல்லது **கடவுச்சொல்** உள்ள சுயவிவரம் அதைக் கேட்கும்;
- **சுற்றிப் பார்க்கிறேன்** உள்நுழையாமல் பொதுப் படங்களை மட்டும் காட்டும். நூலகம் தனிப்பட்டதாக இருக்க
  வேண்டுமெனில், நிர்வாகப் பக்கத்தின் *அமைப்புகள்* இல் இதை அணைக்கவும்.

நிர்வாகிகள் `http://<கணினி>:8080/admin` இல் பயனர்பெயர், கடவுச்சொல்லுடன் உள்நுழைவார்கள்.
படத்தொகுப்பிலிருந்து வெளியேற, மேலே வலப்புறம் உள்ள உங்கள் சுயவிவரத்தைத் திறந்து *சுயவிவரத்தை மாற்று* என்பதைத் தேர்வு செய்யவும்.

## 5. படத்தொகுப்பைப் பயன்படுத்துதல்

- **காலவரிசை** — புதியவை முதலில்; ஓர் ஆண்டுக்குத் தாவ வலப்புறத் தேதிப் பட்டையை இழுக்கவும்.
- **கோப்புறைகள்** — இடப்புற மெனுவில் எண்ணிக்கையுடன்.
- **தேடல்** — கோப்புப் பெயர், கோப்புறை, ஆண்டு அல்லது மாதம், கேமரா பெயர்.
- **பார்வை** — ஒரு படத்தைத் தொடவும். நகர்த்த இழுக்கவும் அல்லது ← → பயன்படுத்தவும்; மூட Esc.
  ♡ விருப்பங்களில் சேர்க்கும்; ⓘ தேதி, அளவு, கேமராவைக் காட்டும்; ⬇ மூலக் கோப்பைப் பதிவிறக்கும்.
- **தேர்வு** — ஒரு நாளுக்கு *அனைத்தையும் தேர்ந்தெடு*, அல்லது படங்களைக் குறிக்கவும்; பின் ஆல்பத்தில்
  சேர்க்கலாம் அல்லது சேர்த்துப் பதிவிறக்கலாம்.
- **ஆல்பங்கள்** — தேர்விலிருந்து ஆல்பம் உருவாக்கலாம்; ஆல்பங்களைப் பகிரலாம்.
- **மொழி** — மேலே உள்ள மொழிப் பொத்தானில் English அல்லது தமிழ். ஒவ்வொருவரின் தேர்வும் நினைவில் இருக்கும்.

## 6. குடும்பத்துக்கு வெளியே ஒருவருடன் பகிர்தல்

பார்வையிலிருந்தோ ஓர் ஆல்பத்திலிருந்தோ **பகிர்** என்பதைத் தேர்வு செய்யவும். கடவுச்சொல்லும் காலாவதித் தேதியும்
சேர்க்கலாம். இணைப்பை உங்கள் வீட்டு நெட்வொர்க்கில் உள்ள ஒருவருக்கு அனுப்பவும். அவர் அந்தப் படத்தையோ
ஆல்பத்தையோ மட்டும் — இடம், கேமரா விவரங்கள் இல்லாத நகலாகப் — பார்ப்பார். உங்கள் இணைப்புகளின் பட்டியல்
உங்கள் சுயவிவரத்தில் உள்ளது; எப்போது வேண்டுமானாலும் ஓர் இணைப்பை நிறுத்தலாம்.

> இணைப்புகள் உங்கள் வீட்டு நெட்வொர்க்கில் மட்டுமே வேலை செய்யும். நினைவு லைட் இணையத்திலிருந்து அணுகப்படுவதற்காக அல்ல.

## 7. பராமரிப்பு

- **காப்புப் பிரதிகள்** — ஒவ்வொரு நாளும் நினைவு லைட் தன் அட்டவணையின் (மக்கள், ஆல்பங்கள், விருப்பங்கள்,
  தெரிவுநிலை) நகலைத் தரவுக் கோப்புறையில் வைத்து, கடைசி ஏழை வைத்திருக்கும். *அமைப்புகள் →
  காப்புப்பிரதியைப் பதிவிறக்கு* வேறு இடத்தில் வைக்க ஒன்றைத் தரும். உங்கள் படங்கள் உங்கள் சொந்தக் கோப்புகள்:
  வழக்கம் போல அவற்றைக் காப்புப் பிரதி எடுங்கள்.
- **தரவுக் கோப்புறை** — Windows-இல் `%LOCALAPPDATA%\Ninaivu-lite`, macOS-இல்
  `~/Library/Application Support/Ninaivu-lite`, Linux-இல் `~/.local/share/ninaivu-lite`.
  இதில் அமைப்புகள், அட்டவணை, முன்னோட்டங்கள், பதிவுகள் இருக்கும்; உங்கள் படங்கள் இருக்காது.
- **நிர்வாகிக் கடவுச்சொல் மறந்துவிட்டதா?** நினைவு லைட்டை மூடி, அந்தக் கணினியில்
  `python -m ninaivu_lite --reset-password <பயனர்பெயர்>` இயக்கவும் (கோப்புறைக்குள், Windows-இல்
  `.venv\Scripts\activate` பிறகு; மற்றவற்றில் `source .venv/bin/activate` பிறகு).
- **இயக்ககம் துண்டிக்கப்பட்டதா?** அதன் படங்கள் கிடைக்கவில்லை எனக் காட்டப்படும்; மீண்டும் இணைத்ததும்
  திரும்பும். எதுவும் இழக்கப்படாது.
- **புதுப்பித்தல்** — நிரல் கோப்புகளைப் புதிய பதிப்பால் மாற்றி மீண்டும் தொடங்கவும். தரவுக் கோப்புறை அப்படியே இருக்கும்.

## 8. நினைவுக்கு மேம்படுத்தல் (விருப்பம்)

பின்னர் முகங்கள், விவரணைத் தேடல், மேகக் காப்புப் பிரதி வேண்டுமெனில், முழு நினைவு உங்கள் நூலகத்தை
எடுத்துக்கொள்ளும். `python -m ninaivu_lite --export lite-export.json` இயக்கி அந்தக் கோப்பை நினைவுக்குக்
கொடுக்கவும். விவரம்: [UPGRADE.md](UPGRADE.md).

## 9. பொதுவான கேள்விகள்

**கைப்பேசியில் முகவரி திறக்கவில்லை.** சாளரத்தில் காட்டப்படும் முகவரியைப் பயன்படுத்தவும் (`localhost` அல்ல);
கைப்பேசி அதே Wi-Fi-இல் உள்ளதா எனப் பார்க்கவும்; Windows firewall கேட்கும்போது Python-ஐ அனுமதிக்கவும்.

**சில காணொளிகள் வெற்று ஓடாகத் தெரிகின்றன.** முன்னோட்டப் படங்களுக்கு `ffmpeg` நிறுவவும். உலாவியால்
இயக்க முடியாத காணொளிகளைப் பதிவிறக்கலாம்.

**iPhone HEIC படங்கள் வெற்று ஓடாகத் தெரிகின்றன.** `.venv\Scripts\pip install pillow-heif` (Windows)
அல்லது `.venv/bin/pip install pillow-heif` இயக்கி மீண்டும் தொடங்கவும்.

**8080 போர்ட் பயன்பாட்டில் உள்ளது.** நினைவு லைட் அடுத்த காலியான போர்ட்டைப் பயன்படுத்தி அதைக் காட்டும்;
அல்லது `--port` மூலம் தேர்வு செய்யவும்.
