# நினைவு லைட் — பயனர் வழிகாட்டி

[Read in English](USER-GUIDE.md) · திரைப்பிடிப்புகளுடன் அச்சிடக்கூடிய வழிகாட்டி: [PDF, தமிழ்](Ninaivu-Lite-User-Guide-Tamil.pdf) · [PDF, English](Ninaivu-Lite-User-Guide-English.pdf)

நினைவு லைட் உங்கள் குடும்பப் புகைப்படங்களையும் காணொளிகளையும் வீட்டிலுள்ள அனைவருக்கும், அதே Wi-Fi-இல்
உள்ள எந்தக் கைப்பேசி, டேப்லெட், கணினியிலும் காட்டுகிறது. இது உங்கள் புகைப்படக் கோப்புறைகளை
**படிக்க மட்டுமே** செய்யும்: எந்தப் படத்தையும் நகர்த்தவோ, திருத்தவோ, நீக்கவோ செய்யாது.
(இறக்குமதி பழைய டிரைவ்களிலிருந்து படங்களை நூலகத்து*க்குள்* நகலெடுக்கும்; சுடர் திருத்திய *நகலை*
அசலின் அருகில் சேமிக்கலாம். இரண்டுமே உங்களிடம் உள்ள எந்தப் படத்தையும் மாற்றாது.)

## 1. தொடங்குதல்

**நிறுவி (installer) மூலம்** (releases பக்கத்திலிருந்து): அதை இயக்கவும். Windows-இல் அது முடிந்ததும்
Control Panel திறக்கும் — **Start** அழுத்தி, பின் **Open the family app** அழுத்தவும். வேறு எதுவும் தேவையில்லை;
கீழே உள்ள *கட்டுப்பாட்டுப் பலகம்* பகுதிக்குச் செல்லலாம். நிறுவிகளுக்கு இன்னும் குறியீட்டுக் கையொப்பம்
(code signing) இல்லை; அதனால் Windows *Windows protected your PC* எனச் சொல்லலாம் (**More info → Run anyway**).
கணினியின் எல்லாப் பயனர்களுக்கும் நிறுவினால் நிர்வாகி அனுமதி கேட்கும்.

**Linux-இல்** `sh Ninaivu-Lite-<version>-linux-amd64.sh` இயக்கவும் (Raspberry Pi-இல் `-arm64.sh`).
உங்கள் சொந்தக் கணக்கில் இயக்கினால் எல்லாம் உங்கள் கணக்கிலேயே இருக்கும்; கணினி தொடங்கும்போது இதுவும்
தொடங்கும். `sudo` உடன் இயக்கினால் (சர்வர், அல்லது வீட்டினர் அனைவரும் பயன்படுத்தும் கணினி) அது தனக்கென
உள்ள `ninaivu-lite` கணக்கில் இயங்கும்; பகுதி 7-இல் *Linux-இல் sudo உடன் நிறுவியிருந்தால்* பார்க்கவும்.

**எதையும் நிறுவாமல்** (Windows): releases பக்கத்திலிருந்து `…-windows-x64-portable.zip` ஐப்
பதிவிறக்கி, அதன் மீது வலது சொடுக்கி *Properties* → *Unblock* தேர்ந்தெடுத்து, பின் *Extract All* மூலம்
நிலையான ஒரு கோப்புறையில் (அல்லது பென்டிரைவில்) விரிக்கவும். அது உருவாக்கும் `Ninaivu Lite`
கோப்புறையைத் திறந்து **`Ninaivu Lite.exe`** (கட்டுப்பாட்டுப் பலகம்) ஐ இருமுறை சொடுக்கவும். எல்லாமே அந்தக்
கோப்புறைக்குள் இருக்கும்; அதன் மேல்மட்டத்தில் `Ninaivu Lite.exe` உம் அதன் பதிவுக் கோப்பு `Ninaivu Lite.log`
உம் மட்டுமே: நிரல் `app` கோப்புறையில்; குடும்பத்தின் அமைப்புகள், நபர்கள், அட்டவணை முதல் முறை அதன்
அருகில் உருவாகும் `data` கோப்புறையில். புதுப்பிக்க, முதலில் பழைய நகலின் Control Panel-இல் **Stop** அழுத்தி அதை மூடுங்கள்; பின் புதிய பதிப்பை ஒரு புதிய கோப்புறையில் விரித்து, பழைய `data` கோப்புறையை
அதன் `Ninaivu Lite` கோப்புறைக்குள் நகலெடுக்கவும்; பழைய நகல் நீங்கள் உள்நுழையும்போது தொடங்கினால், முதலில் அதன் Control Panel-இல்
அதை அணைத்து, புதியதில் இயக்கவும். நகர்த்த அல்லது நீக்க `app\README-PORTABLE.txt` ஐப் பார்க்கவும்.

**நிறுவி இல்லாமல், மூலக் குறியீட்டிலிருந்து:**

1. python.org இலிருந்து **Python 3.10 அல்லது புதியதை** நிறுவவும். Windows-இல்
   *Add python.exe to PATH* என்பதைத் தேர்ந்தெடுக்கவும்.
2. நினைவு லைட்டைப் பதிவிறக்கி, நிலையான ஓர் இடத்தில் விரிக்கவும் (எ.கா. `C:\Ninaivu-lite`).
3. **`start.cmd`** ஐ இருமுறை சொடுக்கவும் (Windows), அல்லது **`./start.sh`** இயக்கவும் (macOS, Linux).
   முதல் முறை ஓரிரு நிமிடங்கள் ஆகும்; ஒருமுறை இணையம் தேவை.
4. உலாவி `http://localhost:8080` இல் திறக்கும். சாளரத்தில் `http://192.168.1.20:8080` போன்ற
   முகவரியும் காட்டப்படும் — அதைக் கைப்பேசிகளிலும் டேப்லெட்டுகளிலும் திறக்கவும்.

குடும்பத்தினர் பயன்படுத்தும்போது சாளரத்தைத் திறந்தே வைத்திருங்கள்; மூடினால் நினைவு லைட் நின்றுவிடும்.

### கட்டுப்பாட்டுப் பலகம் (Control Panel)

முதல் முறை அமைப்பு முடிந்ததும் **Control Panel** தானாகத் திறக்கும். எப்போது வேண்டுமானாலும்
**`Start - Ninaivu Lite Control Panel.vbs`** ஐ இருமுறை சொடுக்கித் திறக்கலாம் (Windows); macOS, Linux-இல்
`./start.sh --panel`. நினைவு லைட் இயங்குகிறதா, எந்த முகவரியில் திறக்க வேண்டும் என்பதை அது காட்டும். அதில்:

- **Start**, **Stop**, **Restart** — இங்கிருந்து தொடங்கினால் நினைவு லைட் பின்னணியில் இயங்கும்;
  சாளரத்தைத் திறந்து வைக்க வேண்டியதில்லை;
- **Open the family app**, **Open the console** — படத்தொகுப்பையும் நிர்வாகப் பக்கத்தையும் திறக்க;
- **Start Ninaivu Lite when I sign in** — ஒருமுறை தேர்ந்தெடுத்தால் கணினியுடன் சேர்ந்து தொடங்கும்;
- **Open the log**, **Open the data folder** — ஏதேனும் சிக்கலைப் பார்க்க வேண்டியபோது.

நினைவு லைட் தானாகப் புதிய பதிப்பைத் தேடுவதில்லை; GitHub உட்பட எங்கும் எதுவும் கேட்பதில்லை. புதிய
நிறுவுகோப்பை இயக்கும் முன் **Stop** அழுத்தி, Control Panel-ஐ மூடுங்கள் (கீழே *புதுப்பித்தல்* பார்க்கவும்).

Control Panel-ஐ மூடினாலும் நினைவு லைட் தொடர்ந்து இயங்கும். (Control Panel ஆங்கிலத்தில் மட்டும் உள்ளது.)
திரை இல்லாத Raspberry Pi அல்லது சர்வரில், கணினி தொடங்கும்போதே நினைவு லைட்டைத் தொடங்கும் சேவையை
(service) Linux நிறுவி அமைக்கும். `sudo` உடன் நிறுவியிருந்தால் Control Panel இருக்காது:
`sudo systemctl start|stop|restart ninaivu-lite` பயன்படுத்தவும்.

## 2. முதல் நாள்

1. முதல் வருகையில் **நிர்வாகிக் கணக்கை உருவாக்கச்** சொல்லும்: உங்கள் பெயர், பயனர்பெயர், குறைந்தது
   8 எழுத்துகள் கொண்ட கடவுச்சொல். கைப்பேசியிலிருந்து அமைத்தால், சிறிய **அமைப்புக் குறியீட்டையும்**
   கேட்கும். Control Panel அதைக் காட்டும்; நினைவு லைட் தொடங்கப்பட்ட சாளரத்திலும் (மூலக் குறியீட்டிலிருந்து
   இயக்கினால்) அது அச்சிடப்படும், தரவுக் கோப்புறையின் `logs/ninaivu-lite.log` இலும் எழுதப்படும்
   (*Open the log*). Linux சேவையில் `journalctl -u ninaivu-lite | grep code` இயக்கவும் (`sudo` இல்லாமல்
   நிறுவியிருந்தால் `--user` சேர்க்கவும்); Docker-இல் `docker logs ninaivu-lite`.
2. பின் நிர்வாகப் பக்கம் உதவும்:
   - **புகைப்படக் கோப்புறையைத் தேர்வு செய்யுங்கள்** — அதைத் தேடிச் சென்று *இந்தக் கோப்புறையைப்
     பயன்படுத்து* என்பதை அழுத்தவும். மேலும் கோப்புறைகளைப் பின்னர் *நூலக அமைப்புகள்* இல் சேர்க்கலாம்.
   - **பழைய புகைப்படங்களைக் கொண்டு வாருங்கள்** — பழைய டிரைவ்கள், மெமரி கார்டுகள், ஃபோன் காப்புப்
     பிரதிகள், காப்புக் கோப்புறைகள் ஆகியவற்றில் எவை புகைப்படங்களை வைத்திருக்கின்றன என வழிகாட்டி
     கேட்கும். ஒவ்வொன்றின் மேல் கோப்புறையைச் சேர்த்தால் போதும்: அதற்குள் உள்ள அனைத்தும், எவ்வளவு
     ஆழமாக இருந்தாலும், தேடப்படும். *இறக்குமதியைத் தொடங்கு* என்பதை அழுத்தினால், படங்கள் உங்கள்
     நூலகக் கோப்புறைக்குள் ஒரு காப்பகத்தில், எடுத்த நாள் வாரியாக, ஒவ்வொரு நகலும் சரிபார்க்கப்பட்டு
     நகலெடுக்கப்படும். அசல்கள் ஒருபோதும் மாற்றப்படவோ, நகர்த்தப்படவோ, நீக்கப்படவோ மாட்டா. கொண்டு வர
     எதுவும் இல்லையெனில் தவிர்க்கலாம்; *நூலகம்* இன் கீழ் உள்ள *இறக்குமதி* எப்போதும் இதையே செய்யும்.
   - **குடும்பத்தினரைச் சேருங்கள்** — *நபர்கள்* பக்கத்தில் *ஒருவரைச் சேர்*: பெயர், பாத்திரம்,
     உள்ளே வரும் வழி (ரகசியம் இல்லை, PIN, அல்லது கடவுச்சொல்).
3. அட்டவணையிடல் தானாகத் தொடங்கும். கிடைக்கக் கிடைக்கப் படங்கள் தோன்றும்; சிறு முன்னோட்டங்கள் பின்னணியில்
   உருவாகும். பெரிய நூலகத்துக்கு முதல் முறை நேரம் ஆகலாம்; பின்னர் விரைவாகத் தொடங்கும்.
   பல கோர்கள் உள்ள கணினி, ஒன்றைத் தவிர மற்ற எல்லா கோர்களிலும் ஒரே நேரத்தில் முன்னோட்டங்களை
   உருவாக்கும் (Raspberry Pi-யில் மூன்று, எட்டு கோர் மடிக்கணினியில் ஏழு); படத்தொகுப்புக்கு எப்போதும்
   ஒரு கோர் விடப்படும், அதனால் அது வேலை செய்யும்போதே குடும்பத்தினர் படங்களைப் பார்க்கலாம். ஒன்று
   அல்லது இரண்டு கோர்கள் உள்ள கணினி அவற்றை ஒவ்வொன்றாக உருவாக்கும்.

## 3. பாத்திரங்களும் யார் எதைப் பார்க்கலாம் என்பதும்

| பாத்திரம் | செய்யக்கூடியவை |
| --- | --- |
| **நிர்வாகி** | அனைத்தும்: கோப்புறைகள், மக்கள், யார் எதைப் பார்க்கலாம், அமைப்புகள் |
| **குடும்பம்** | பொது, குடும்பப் படங்களைப் பார்த்தல், பதிவிறக்கம், பிடித்தவை, ஆல்பங்கள், பகிர்வு இணைப்புகள் |
| **விருந்தினர்** | பொதுப் படங்கள் மட்டும் |

ஒவ்வொரு படமும் இவற்றில் ஒன்று:

- **பொது** — அனைவரும், விருந்தினர்களும் *சுற்றிப் பார்க்கிறேன்* வருகையாளர்களும் உட்பட
- **குடும்பம்** — குடும்பத்தினரும் நிர்வாகிகளும் (புதிய படங்களுக்கு இயல்புநிலை)
- **மறைக்கப்பட்டவை** — நிர்வாகிகள் மட்டும்

இதை நிர்வாகப் பக்கத்தில் **யார் பார்க்கலாம்** பக்கத்தில் அமைக்கவும்: ஒரு கோப்புறையையும் நிலையையும் தேர்ந்தெடுக்கவும்.
அந்தக் கோப்புறைக்குள் உள்ள அனைத்துக்கும், பின்னர் சேர்க்கப்படும் படங்களுக்கும் அது பொருந்தும்.
நிர்வாகிகள் படத்தொகுப்பில் ஒரு படத்தைப் பார்க்கும்போதே அதை மட்டும் மாற்றலாம். கோப்புறை மாற்றத்தைத்
*அந்த மாற்றத்தைத் திரும்பப்பெறு* மூலம் திருப்பலாம்.

ஒருவருக்கு **ஒரு கோப்புறையை மட்டும்** (எ.கா. `Trips`) கொடுக்கலாம்: அதற்கு வெளியே அவர் எதையும் பார்க்க மாட்டார்.

## 4. உள்நுழைதல்

படத்தொகுப்புப் பக்கத்தில் ஒவ்வொருவரும் தம் படத்தைத் தொடுவார்கள்:

- ரகசியம் இல்லாத சுயவிவரம் உடனே திறக்கும்;
- **PIN** அல்லது **கடவுச்சொல்** உள்ள சுயவிவரம் அதைக் கேட்கும்;
- **சுற்றிப் பார்க்கிறேன்** உள்நுழையாமல் பொதுப் படங்களை மட்டும் காட்டும். நூலகம் தனிப்பட்டதாக இருக்க
  வேண்டுமெனில், நிர்வாகப் பக்கத்தின் *அமைப்புகள்* இல் இதை அணைக்கவும்.

நிர்வாகியின் ஓடு பூட்டப்பட்டிருக்கும்; அது கடவுச்சொல்லைக் கேட்கும். `http://<கணினி>:8080/admin` கட்டுப்பாட்டு மையம் பயனர்பெயர், கடவுச்சொல்லுடன் உள்நுழைய வைக்கும்.
குடும்பம் பகிர்ந்து பயன்படுத்தும் டேப்லெட்டில் வேறொருவராக உள்நுழைந்தால், முன்பு உள்நுழைந்திருந்தவர் அதிலிருந்து
வெளியேற்றப்படுவார்.

**உள்நுழைவுத் திரையில் உங்கள் படம்.** ஒவ்வொரு ஓடும் உங்கள் நிறத்தில் உங்கள் பெயரின் முதலெழுத்துகளுடன் தொடங்கும். அதற்குப் பதிலாக ஒரு புகைப்படத்தைப் பயன்படுத்த, அதைக் காட்சியகத்தில் திறந்து, அதன் ⋯ மெனுவில் *என் சுயவிவரப் படமாகப் பயன்படுத்து* என்பதைத் தேர்ந்தெடுங்கள்: அதன் நடுப்பகுதி உங்கள் பெயருக்கு அருகில் ஒரு சிறிய சதுரமாகும். உங்கள் சுயவிவரத்தில் *படத்தை நீக்கு* முதலெழுத்துகளை மீண்டும் கொண்டுவரும்; நிர்வாகி *நபர்கள்* பகுதியில் யாருடைய படத்தையும் நீக்கலாம். உள்நுழைவுத் திரையைக் காண்பவர் அனைவருக்கும் படம் தெரியும்; எனவே அது குடும்பம் அல்லது பொதுப் படமாக இருக்க வேண்டும். காட்ட விரும்பும் ஒன்றைத் தேர்ந்தெடுங்கள்.
படத்தொகுப்பிலிருந்து வெளியேற, மேலே வலப்புறம் உள்ள உங்கள் சுயவிவரத்தைத் திறந்து *வெளியேறு* (கதவுக் குறி) என்பதைத் தேர்வு செய்யவும்.

## 5. படத்தொகுப்பைப் பயன்படுத்துதல்

- **காலவரிசை** — புதியவை முதலில்; ஒரு மாதம் அல்லது ஆண்டுக்குத் தாவ வலப்புறத் தேதிப் பட்டையை
  இழுக்கவும், அல்லது கீழ் மூலையிலுள்ள தேதிப் பொத்தானைச் சொடுக்கவும் (அல்லது **D** அழுத்தவும்): படங்கள்
  உள்ள ஆண்டுகளும் மாதங்களும் மட்டுமே பட்டியலிடப்படும் (*தேதி இல்லாதது* கடைசியில்); *புதியது முதலில்*,
  *பழையது முதலில்* வரிசைகளில் இது தெரியும். கைபேசியில் புகைப்படங்களுக்கு மேலே ஆண்டுகளின் வரிசை
  இருக்கும்: ஒன்றைத் தொட்டால் அந்த ஆண்டு காட்டப்படும்; தேதிப் பொத்தான் பட்டியலைத் திரையின்
  அடியிலிருந்து திறக்கும்.
- **கோப்புறைகள்** — இடப்புற மெனுவில் எண்ணிக்கையுடன்.
- **தேடல்** — கோப்புப் பெயர், கோப்புறை, ஆண்டு அல்லது மாதம், கேமரா பெயர்.
- **பார்வை** — ஒரு படத்தைத் தொடவும். நகர்த்த இழுக்கவும் அல்லது ← → பயன்படுத்தவும்; மூட Esc.
  ♡ அதை உங்கள் *பிடித்தவை* பட்டியலில் சேர்க்கும்; ⓘ தேதி, அளவு, கேமராவைக் காட்டும்; ⬇ மூலக் கோப்பைப் பதிவிறக்கும்.
- **தேர்வு** — ஒரு நாளுக்கு *அனைத்தையும் தேர்ந்தெடு*, அல்லது படங்களைக் குறிக்கவும் (கைபேசியில் ஒரு படத்தை
  அழுத்திப் பிடித்து, பின் மற்றவற்றைத் தொடவும்); பின் ஆல்பத்தில்
  சேர்க்கலாம் அல்லது சேர்த்துப் பதிவிறக்கலாம்.
- **ஆல்பங்கள்** — தேர்விலிருந்து ஆல்பம் உருவாக்கலாம்; ஆல்பங்களைப் பகிரலாம்.
- **மொழி** — மேலே உள்ள மொழிப் பொத்தானில் English அல்லது தமிழ். ஒவ்வொருவரின் தேர்வும் நினைவில் இருக்கும்.
- **சுடர்** (⋯ → *சுடர் (AI) மூலம் திருத்து*) — உலாவியிலேயே இயங்கும் புகைப்பட ஸ்டுடியோ: ஒளி, நிறம், நுணுக்கம்,
  சட்டக ஸ்லைடர்கள், தோற்றங்கள், படத்திலிருந்து அளந்த பரிந்துரைகள், *சற்று வெப்பமாக்கு* போன்ற
  சாதாரண வார்த்தைகள் (*AI உதவி*), தூரிகையால் ஆடை நிறம். எதுவும் எங்கும் அனுப்பப்படாது, அசல்
  ஒருபோதும் மாறாது: முடிவைப் பதிவிறக்கலாம்; நிர்வாகி *நகலை நினைவு நூலகத்தில் சேமி* மூலம் அசலின்
  அருகில் வைக்கலாம்.
- **தொலைபேசியில்** — அடுத்த முறைகளில் படத்தொகுப்பு விரைவாகத் திறக்கும்: நினைவு லைட் புதுப்பிக்கப்படும்
  வரை தொலைபேசி செயலியின் சொந்தக் கோப்புகளை வைத்திருக்கும், பின்னர் புதியவற்றைத் தானே பெறும்.
  தொலைபேசியைப் பக்கவாட்டில் பிடித்தால், உள்நுழைவுத் திரைகளையும் உரையாடல் பெட்டிகளையும் உருட்டலாம்;
  ஒவ்வொரு பொத்தானையும் எட்டலாம்.
- **பக்கவாட்டுப் படங்கள்** தேடலின்போதே நேராக்கப்படும்: கேமராவின் சொந்தக் குறிப்பால், OpenCV
  விருப்பத்தேர்வு நிறுவியிருந்தால் குறிப்பு இல்லாத படத்தின் முகங்களால். நிர்வாகி ⋯ → *சுழற்று*
  (அல்லது **R**) மூலம் எந்தப் படத்தையும் கையால் சுழற்றலாம்: திறக்கும் பட்டையில் இடம் அல்லது
  வலமாகத் திருப்பி (**R** / **Shift+R**), *சேமி* (**Enter**) அல்லது *ரத்து* (**Esc**). படமும்
  சிறுபடமும் பகிர்வு இணைப்புகள் உட்பட எங்கும் புதிய திசையில் தெரியும்; கோப்பு ஒருபோதும் மாறாது.

### இறக்குமதி: பழைய டிரைவ்கள் ஒரே காப்பகத்தில்

கன்சோலில் *நூலகம் → இறக்குமதி* எத்தனை பழைய டிரைவ்கள், கார்டுகள், காப்புக் கோப்புறைகளிலிருந்தும்
புகைப்படங்களையும் வீடியோக்களையும் `YYYY/MM/DD` என அடுக்கிய ஒரே காப்பகத்தில் சேர்க்கிறது:

1. **மூலங்கள்** — ஒவ்வொரு மேல் கோப்புறையையும் அல்லது டிரைவையும் சேர்க்கவும். உள்ளே உள்ள ஒவ்வொரு
   கோப்புறையும் தேடப்படும்.
2. **இலக்கு** — காப்பகம் கட்டப்படும் இடம். காப்பகத்தின் சொந்த மூலக் கோப்புறையைத் தேர்வுசெய்யவும்;
   அதற்குள் ஒரு கோப்புறையைத் தேர்ந்தால், நினைவு மூலத்தையே பயன்படுத்தி, அதைச் சொல்லும்.
3. **ஓட்டம்** — *ஒன்றுசேர்ப்பைத் தொடங்கு* ஒவ்வொரு கோப்பையும் நகலெடுத்துச் சரிபார்க்கும் (படிக்கும்போதே
   ஹாஷ் செய்து, கணக்கில் வருமுன் காப்பகத்திலிருந்து மீண்டும் படிக்கும்). நகல்கள் உள்ளடக்கத்தால்
   கண்டறியப்பட்டு இருந்த இடத்திலேயே விடப்படும்; ஒரே பெயர் வேறு உள்ளடக்கம் என்றால் `_1` சேர்க்கப்படும்.
   **தொடங்கு என்பதே தொடர்தலும்**: இடைநின்ற ஓட்டம் நின்ற இடத்திலிருந்து தொடரும். *சோதனை ஓட்டம்*
   எல்லாவற்றையும் தீர்மானித்து எதையும் எழுதாது; *காப்பகத்தைத் தணிக்கை செய்* ஒவ்வொரு காப்பகக் கோப்பையும்
   மீண்டும் படித்து ஹாஷைச் சரிபார்க்கும்.

முடிந்ததும் *நூலகத்தில் சேர்* காப்பகத்தைப் படத்தொகுப்பின் பகுதியாக்கும். Google Photos ஏற்றுமதி
(Takeout) அதன் தேதிகள், இடங்கள், விளக்கங்களுடன் வரும்; காப்பகம் அட்டவணைப்படுத்தப்பட்டதும்
*ஆல்பங்களை உருவாக்கு* அதன் ஆல்பங்களை மீண்டும் உருவாக்கும். *பட்டியலை ஏற்றுமதி செய்* ஒவ்வொரு
கோப்பையும் அதன் ஹாஷுடன் பட்டியலிடும்.

### பென்டிரைவ், வெளி டிரைவ் அல்லது தொலைபேசி இணைக்கப்பட்டால்

நினைவு லைட் இயங்கும் கணினியில் USB பென்டிரைவ், மெமரி கார்டு, வெளி ஹார்ட் டிரைவ் அல்லது
தொலைபேசியை (கேபிள் மூலம்) இணையுங்கள். எந்தப் பெட்டியும் மேலே தோன்றாது: எந்தப் பக்கம் திறந்திருந்தாலும்,
கன்சோலின் மேலே அந்த டிரைவ் ஓர் **அறிவிப்பாகத்** தோன்றும். (கட்டுப்பாட்டுப் பலகம் திறந்திருந்தால், அது
தன் சாளரத்திலேயே அதைச் சொல்லி, கன்சோலைத் திறக்கச் சொல்லும்.)

- **இறக்குமதி செய்ய அறிவிப்பையே அழுத்துங்கள்**: அந்த டிரைவை மூலமாகக் கொண்டு *இறக்குமதி* திறக்கும்.
  சேருமிடத்தைச் சரிபார்த்து *ஒன்றுசேர்ப்பைத் தொடங்கு* அழுத்துங்கள். டிரைவில் எதுவும் மாற்றப்படாது.
- அறிவிப்பின் கீழுள்ள **ஏற்றுமதி** நூலகத்தின் படங்களையும் காணொளிகளையும் நூலகத்தின் கோப்புறை
  அமைப்பிலேயே டிரைவில் `Ninaivu Lite` கோப்புறையில் நகலெடுக்கும். அறிவிப்பிலேயே முன்னேற்றமும்
  *நிறுத்து* பொத்தானும் தெரியும். அடுத்த முறை புதியவை மட்டுமே நகலெடுக்கப்படும்; டிரைவில் ஏற்கெனவே
  உள்ள எதுவும் மேலெழுதப்படாது, நீக்கப்படாது.
- **மீண்டும் கேட்காதே** — அந்த டிரைவை வேறொரு நாள் இணைத்தாலும் இனி அதைப் பற்றிச் சொல்லாது. இதை
  மாற்ற, *அமைப்புகள்* பக்கத்தில் *இணைக்கப்படும் டிரைவ்கள்* கீழ் *மீண்டும் கேள்* அழுத்துங்கள்.
- **×** அறிவிப்பை மூடும்; அடுத்த முறை டிரைவை இணைக்கும்போது மீண்டும் வரும்.

கணினியின் சொந்த வட்டுகளுக்கும், நூலகமே இருக்கும் டிரைவுக்கும் அறிவிப்பு வராது.

**தொலைபேசிக்கு** *ஏற்றுமதி* இல்லை: அதன் அறிவிப்பை அழுத்தினால் அதிலிருந்து இறக்குமதி ஆகும்.
தொலைபேசியைத் திறந்து *File transfer* (Android) அல்லது *Trust this computer* (iPhone) என்பதைத்
தேர்ந்தெடுங்கள்; இல்லையெனில் Windows அதன் படங்களைப் பார்க்க முடியாது. Windows-இல் நினைவு லைட்
கேமரா கோப்புறைகளை (DCIM, Pictures, Movies) கேபிள் வழியாக நகலெடுத்து, காப்பகத்தில் இறக்குமதி செய்து,
பின் தன் தற்காலிக நகல்களை நீக்கும்; அடுத்த முறை புதிய படங்கள் மட்டுமே வரும். தொலைபேசியில் எதுவும்
மாற்றப்படாது. Linux-இல் முதலில் கோப்பு மேலாளரில் தொலைபேசியைத் திறவுங்கள்; Mac-இல் தொலைபேசிகள்
கண்டறியப்படாது. Linux-இல் `sudo` உடன் நிறுவியிருந்தால், நினைவு லைட் தனக்கென உள்ள கணக்கில் இயங்குவதால்,
உங்கள் desktop திறக்கும் டிரைவ்களையும் தொலைபேசிகளையும் அது காணாமல் போகலாம்: அவற்றின் கோப்புறைகளை
*இறக்குமதி* பக்கத்தில் நீங்களே சேர்க்கவும்.

## 6. குடும்பத்துக்கு வெளியே ஒருவருடன் பகிர்தல்

பார்வையில் **பகிர்வு இணைப்பு**, அல்லது ஓர் ஆல்பத்தில் **ஆல்பத்தைப் பகிர்** என்பதைத் தேர்வு செய்யவும். கடவுச்சொல்லும் காலாவதித் தேதியும்
சேர்க்கலாம்; இணைப்பு உள்ள எவரும் கடவுச்சொல்லை ஒரு நாளில் அதிகபட்சம் 60 முறை மட்டுமே முயல முடியும். இணைப்பை உங்கள் வீட்டு நெட்வொர்க்கில் உள்ள ஒருவருக்கு அனுப்பவும். அவர் அந்தப் படத்தையோ
ஆல்பத்தையோ மட்டும் — இடம், கேமரா விவரங்கள் இல்லாத நகலாகப் — பார்ப்பார். காணொளியின் இருப்பிடத்தை நீக்கக்
கணினியில் ffmpeg தேவை; அது இல்லையென்றால், நிர்வாகி அமைப்புகளில் *இருப்பிடத்தை நீக்க முடியாத காணொளிகளை
விருந்தினர்களுக்கும் பகிர்வு இணைப்புகளுக்கும் அப்படியே அனுப்பு* என்பதை இயக்காதவரை, அந்தக் காணொளி பகிரப்படாது. உங்கள் இணைப்புகளின் பட்டியல்
உங்கள் சுயவிவரத்தில் உள்ளது; எப்போது வேண்டுமானாலும் ஓர் இணைப்பை நிறுத்தலாம். மறைக்கப்பட்ட படத்தைப்
பகிர முடியாது (முதலில் அதைக் குடும்பம் அல்லது பொது என மாற்றவும்); பின்னர் மறைக்கப்பட்ட படத்தின் இணைப்பு
வேலை செய்வதை நிறுத்தும். பார்ப்பவருக்குக் கோப்பின் பெயர் தெரியாது.

> இணைப்புகள் உங்கள் வீட்டு நெட்வொர்க்கில் மட்டுமே வேலை செய்யும். நினைவு லைட் இணையத்திலிருந்து அணுகப்படுவதற்காக அல்ல.

## 7. பராமரிப்பு

- **காப்புப் பிரதிகள்** — ஒவ்வொரு நாளும் நினைவு லைட் ஒரு முழு மீட்பு zip-ஐ (மக்கள், ஆல்பங்கள், பிடித்தவை,
  பகிர்வு இணைப்புகள், தெரிவுநிலை கொண்ட அட்டவணை, அமைப்புகள், சுயவிவரப் படங்கள்) தரவுக் கோப்புறையின்
  `backups/`-இல் உருவாக்கும். கடைசி ஏழு நாட்களுடையவை, பிறகு நான்கு வாரங்களுக்கு வாரம் ஒன்று, மூன்று
  மாதங்களுக்கு மாதம் ஒன்று வைக்கப்படும்; நூலகக் கோப்புறையோ ஒரு நபரோ நீக்கப்படும் முன்பும் ஒரு நகல்
  எடுக்கப்படும். *அமைப்புகள்* அவற்றைப் பட்டியலிட்டு, கடைசி நகல் தோல்வியடைந்திருந்தால் சொல்லும்.
  *அமைப்புகள் → காப்புப்பிரதியைப் பதிவிறக்கு* வேறு இடத்தில் வைக்க ஒன்றைத் தரும்; அதில் எல்லோருடைய
  கடவுச்சொல், PIN சரிபார்ப்புகளும் பகிர்வு இணைப்புகளும் உள்ளதால் அதைத் தனிப்பட்டதாக வைத்திருங்கள்.
  ஒன்றைத் திரும்ப வைக்க, நினைவு லைட்டை நிறுத்தி, கீழே உள்ள கட்டளையை `--restore <zip>` உடன்
  இயக்கவும்; முன்பு இருந்தவை தரவுக் கோப்புறைக்குள் `before-restore-…` கோப்புறையில் வைக்கப்படும்,
  நீக்கப்படாது; பிறகு எல்லோரும் மீண்டும் உள்நுழைய வேண்டும். புதிய கணினியில் படக் கோப்புறைகள் வேறு
  இடத்தில் இருந்தால், *நூலக அமைப்புகள்* இல் கண்டுபிடிக்க முடியாத ஒவ்வொரு கோப்புறைக்கும் அருகிலுள்ள **இடம் மாறியதா?**
  என்பதைப் பயன்படுத்தவும். உங்கள் படங்கள் zip-இல் இல்லை: அவை உங்கள் சொந்தக் கோப்புகள்,
  எனவே வழக்கம் போல அவற்றைக் காப்புப் பிரதி எடுங்கள்.
- **தரவுக் கோப்புறை** — Windows-இல் `%LOCALAPPDATA%\Ninaivu-lite`, macOS-இல்
  `~/Library/Application Support/Ninaivu-lite`, Linux-இல் `~/.local/share/ninaivu-lite`;
  கையடக்க zip-க்கு நிரலின் அருகில் உள்ள `data` கோப்புறை; Linux-இல் `sudo` உடன் நிறுவியிருந்தால்
  `/var/lib/ninaivu-lite`; Docker-இல் `ninaivu_lite_data` volume. இதில் அமைப்புகள், அட்டவணை,
  முன்னோட்டங்கள், காப்புப் பிரதிகள், பதிவுகள் இருக்கும்; உங்கள் படங்கள் இருக்காது.
- **நிர்வாகிக் கடவுச்சொல் மறந்துவிட்டதா?** நினைவு லைட்டை நிறுத்தி, அந்தக் கணினியில், நிறுவிய
  விதத்துக்கு ஏற்ற கட்டளையை இயக்கவும் (`--restore <zip>` உம் இதே இடத்தில்தான்):
  - **Windows நிறுவி, அல்லது `sudo` இல்லாத Linux:** `ninaivu-lite --reset-password <பயனர்பெயர்>`
    (Windows-இல் புதிய Command Prompt-இல்).
  - **`sudo` உடன் Linux:** `sudo systemctl stop ninaivu-lite`, பிறகு
    `sudo -u ninaivu-lite /usr/local/bin/ninaivu-lite --reset-password <பயனர்பெயர்>`, பிறகு
    `sudo systemctl start ninaivu-lite`.
  - **கையடக்க zip:** அதன் `Ninaivu Lite` கோப்புறையில், `app\Python\python.exe -m ninaivu_lite
    --data "<அந்தக் கோப்புறை>\data" --reset-password <பயனர்பெயர்>`.
  - **மூலக் குறியீட்டின் நகல்:** `python -m ninaivu_lite --reset-password <பயனர்பெயர்>` (கோப்புறைக்குள்,
    Windows-இல் `.venv\Scripts\activate` பிறகு; மற்றவற்றில் `source .venv/bin/activate` பிறகு).
  - **Docker:** `docker compose -f installers/docker/docker-compose.yml run --rm ninaivu-lite
    python -m ninaivu_lite --data /data --reset-password <பயனர்பெயர்>`.
- **இயக்ககம் துண்டிக்கப்பட்டதா?** அதன் படங்கள் கிடைக்கவில்லை எனக் காட்டப்படும்; மீண்டும் இணைத்ததும்
  திரும்பும். எதுவும் இழக்கப்படாது. இறக்குமதியின்போது துண்டிக்கப்பட்டால், இறக்குமதி முடியவில்லை
  எனக் காட்டப்படும்: மீண்டும் இணைத்து *Start* அழுத்தி முடிக்கவும். பென்டிரைவுக்கு நகலெடுத்த பிறகு,
  பிடுங்கும் முன் அதை வெளியேற்றுங்கள் (Eject).
- **நூலகக் கோப்புறை இடம் மாறியதா, அல்லது தேவையில்லையா?** *நூலக அமைப்புகள்* இல் கண்டுபிடிக்க முடியாத கோப்புறைக்கு அருகிலுள்ள **இடம் மாறியதா?**
  அதை அதன் புதிய இடத்துக்குக் காட்டி, எல்லாவற்றையும் வைத்துக்கொள்ளும். *நீக்கு* அதைப்
  படத்தொகுப்பிலிருந்து எடுக்கும்; அதே கோப்புறையை மீண்டும் சேர்த்தால், யார் எதைப் பார்க்கலாம், பிடித்தவை,
  ஆல்பங்கள், பகிர்வு இணைப்புகள் திரும்ப வரும்.
- **புதுப்பித்தல்** — நினைவு லைட் புதிய பதிப்பைத் தானாகச் சோதிப்பதில்லை; நீங்கள் விரும்பும்போது
  வெளியீட்டுப் பக்கத்திலிருந்து பதிவிறக்குங்கள். **முதலில் நினைவு லைட்டை நிறுத்துங்கள்**: Control
  Panel-இல் **Stop** அழுத்தி அதை மூடுங்கள்; Linux
  சர்வரில் `sudo systemctl stop ninaivu-lite`. பின் நிறுவியில், புதிய நிறுவியை இயக்கவும்;
  Linux-இல், புதிய `.sh` ஐ முதல் முறை போலவே இயக்கவும்; Mac-இல் புதிய செயலியை Applications-இல்
  உள்ள பழையதன் மேல் இழுத்து விடுங்கள். கையடக்க zip-க்கு, புதிய
  பதிப்பை ஒரு புதிய கோப்புறையில் விரித்து, பழைய `data` கோப்புறையை அதற்குள் நகலெடுக்கவும் (முதலில்
  பழைய நகலில் உள்நுழையும்போது தொடங்குவதை அணைக்கவும்). மூலக்
  குறியீட்டின் நகலுக்கு, நிரல் கோப்புகளைப் புதிய பதிப்பால் மாற்றி மீண்டும் தொடங்கவும். தரவுக் கோப்புறை
  அப்படியே இருக்கும். புதுப்பித்த பின் முதல் தொடக்கத்தில் அட்டவணை தானாகப் புதிய வடிவத்துக்கு
  மாறும்; அதற்கு முன் அதன் பழைய நகல் ஒன்று (`backups/before-update-…zip`) வைக்கப்படும். நினைவு
  லைட் இயங்கும்போதே Mac செயலி மாற்றப்பட்டால், பழைய பதிப்பு இன்னும் இயங்குவதாக Control Panel
  சொல்லும்: **Restart** அழுத்துங்கள். 1.11.1-இலிருந்து 1.11.0, 1.10.0, 1.9.0, 1.8.0 அல்லது 1.7.0-க்குத் திரும்ப எதுவும் தேவையில்லை. 1.6.0 அல்லது அதற்கு
  முந்தைய பதிப்புக்குத் திரும்ப, புதுப்பிப்பதற்கு முன் எடுத்த காப்புப் பிரதியை மீட்டெடுக்க வேண்டும்:
  1.7.0 அல்லது அதற்குப் பிந்தைய பதிப்பின் அட்டவணையைப் பதிப்பு 1.6.0 திறக்க முடியாது.
- **Linux-இல் `sudo` உடன் நிறுவியிருந்தால்** — நினைவு லைட் ஒரு சேவையாக, தனக்கென உள்ள `ninaivu-lite`
  கணக்கில் இயங்கும் (root ஆக ஒருபோதும் இல்லை); அதன் தரவு `/var/lib/ninaivu-lite`-இல் இருக்கும். அந்தக்
  கணக்கு உங்கள் புகைப்படக் கோப்புறைகளைப் படிக்கவும், அவற்றுக்கு மேலே உள்ள ஒவ்வொரு கோப்புறை வழியாகவும்
  செல்லவும் முடிய வேண்டும். அது படிக்க முடியாதவற்றை நிறுவி பெயரிட்டுச் சொல்லும்; எடுத்துக்காட்டாக இப்படி
  அனுமதிக்கலாம்: `sudo setfacl -R -m u:ninaivu-lite:rX /home/me/Pictures` (இப்போது உள்ளவை),
  `sudo setfacl -R -d -m u:ninaivu-lite:rX /home/me/Pictures` (பின்னர் சேர்பவை),
  `sudo setfacl -m u:ninaivu-lite:x /home/me` (மேலே உள்ள ஒவ்வொரு கோப்புறையும்), பிறகு
  `sudo systemctl restart ninaivu-lite`.

## 8. நினைவுக்கு மேம்படுத்தல் (விருப்பம்)

பின்னர் முகங்கள், விவரணைத் தேடல், மேகக் காப்புப் பிரதி வேண்டுமெனில், முழு நினைவு உங்கள் நூலகத்தை
எடுத்துக்கொள்ளும். `python -m ninaivu_lite --export lite-export.json` இயக்கி (நிறுவியில்
`ninaivu-lite --export lite-export.json`; மற்றவற்றில், பகுதி 7-இல் கடவுச்சொல் மறந்தால் தரப்பட்ட கட்டளையை
`--reset-password` க்குப் பதிலாக `--export lite-export.json` உடன்) அந்தக் கோப்பை நினைவுக்குக் கொடுக்கவும்.
விவரம்: [UPGRADE.md](UPGRADE.md).

## 9. பொதுவான கேள்விகள்

**கைப்பேசியில் முகவரி திறக்கவில்லை.** Control Panel அல்லது சாளரத்தில் காட்டப்படும் முகவரியைப் பயன்படுத்தவும்
(`localhost` அல்ல); கைப்பேசி அதே Wi-Fi-இல் உள்ளதா எனப் பார்க்கவும்; Windows firewall கேட்கும்போது
Python-ஐ அனுமதிக்கவும். Linux-இல், firewall வழியாக 8080 போர்ட்டை அனுமதிக்கவும்:
`sudo ufw allow 8080/tcp` (Ubuntu, Raspberry Pi OS) அல்லது
`sudo firewall-cmd --permanent --add-port=8080/tcp && sudo firewall-cmd --reload` (Fedora).

**"This address is not one Ninaivu Lite answers to." என்று வருகிறது.** நினைவு லைட் இந்தக் கணினியின்
சொந்தப் பெயர்களுக்கு மட்டுமே பதில் அளிக்கும்: அதன் முகவரிகள் (`http://192.168.1.20:8080` போன்றவை),
நெட்வொர்க்கில் அதன் பெயர் (`mypc` அல்லது `mypc.local`), `localhost`. வேறு பெயரைப் பயன்படுத்த (உங்கள்
சொந்தப் பெயர், அல்லது reverse proxy), நினைவு லைட்டை நிறுத்தி, தரவுக் கோப்புறையிலுள்ள `settings.json`-இல்
`"allowed_hosts"` இல் அதைச் சேர்க்கவும் (எ.கா. `"allowed_hosts": ["photos.home"]`), அல்லது
`NINAIVU_ALLOWED_HOSTS` சூழல் மாறியில் (environment variable) காற்புள்ளிகளால் பிரித்துச் சேர்க்கவும்
(Docker-இல் `ALLOWED_HOSTS`); பிறகு மீண்டும் தொடங்கவும்.

**"Ninaivu Lite answers only the home network." என்று வருகிறது.** தொலைபேசியோ கணினியோ இணையம் வழியாக
(router இல் திறந்த port அல்லது tunnel மூலம் mobile data இல்) நினைவு லைட்டை அடைகிறது. குடும்பப்
புகைப்படங்கள் தவறுதலாக இணையத்தில் வெளிப்படாமல் இருக்க அது மறுக்கப்படுகிறது. வீட்டு Wi-Fi உடன்
இணையுங்கள், அல்லது Tailscale போன்ற தனிப்பட்ட VPN ஐப் பயன்படுத்துங்கள். இணையத்திலிருந்து அடைய
வேண்டுமென்றே விரும்பினால் மட்டும் (உங்கள் சொந்த HTTPS பின்னால்), அதை நிறுத்தி `settings.json`-இல்
`"allow_internet": true` என அமைக்கவும், அல்லது `NINAIVU_ALLOW_INTERNET=1`.

**விருந்தினருக்கோ பகிர்வு இணைப்புக்கோ காணொளியைப் பகிர முடியாது என்று வருகிறது.** கணினியில் `ffmpeg`
நிறுவவும்: காணொளியை அனுப்பும் முன் அதன் இருப்பிடத்தை நீக்க நினைவு லைட்டுக்கு அது தேவை. அல்லது
நிர்வாகியாக, *அமைப்புகள்* இல் *இருப்பிடத்தை நீக்க முடியாத காணொளிகளை விருந்தினர்களுக்கும் பகிர்வு
இணைப்புகளுக்கும் அப்படியே அனுப்பு* என்பதை இயக்கவும் (அப்போது காணொளி தன் இருப்பிடத்துடனே போகும்).

**சில காணொளிகள் வெற்று ஓடாகத் தெரிகின்றன.** குடும்ப உறுப்பினரோ நிர்வாகியோ முதன்முறை அதைக் கடந்து உருட்டும்போது அல்லது இயக்கும்போது காணொளிக்கு முன்னோட்டப் படம் கிடைக்கும்: அவர்களின் உலாவி ஒரு சட்டகத்தை வரைந்து, நினைவு அதை எல்லோருக்கும் வைத்திருக்கும். உலாவியால் இயக்க முடியாத காணொளி வெற்று ஓடாகவே இருக்கும் (அவற்றுக்குக் கணினியில் `ffmpeg` நிறுவவும்); அதைப் பதிவிறக்கலாம்.

**iPhone HEIC படங்கள் வெற்று ஓடாகத் தெரிகின்றன.** `.venv\Scripts\pip install pillow-heif` (Windows)
அல்லது `.venv/bin/pip install pillow-heif` இயக்கி மீண்டும் தொடங்கவும்.

**8080 போர்ட் பயன்பாட்டில் உள்ளது.** நினைவு லைட் அடுத்த காலியான போர்ட்டைப் பயன்படுத்தி அதைக் காட்டும்;
அல்லது `--port` மூலம் தேர்வு செய்யவும்.
